# Zircon Godot 客户端界面与渲染缺陷审计文档

本文档总结并记录了从最新画面截图（例如 `/tmp/sumika-clip-1786195247080710317.png`）中审计出的客户端界面 UI 布局、状态图标缺失及视口偏移等核心缺陷。

---

## 1. 顶部状态/BUFF 图标栏缺失与视口偏移

### 缺陷描述
* **顶部状态/BUFF图标失踪**：在游戏画面顶部中央及偏左位置，原版应有实时状态图标（如增益 Buff、药水状态、特殊标志等），目前完全未显示。
* **画面视口整体向下偏移/裁剪**：
  * 左上角坐标与地图名称（如 `位置:(165,246)`）紧贴屏幕顶边缘甚至部分字符被裁切。
  * 右上角小地图顶部边缘有轻微切边现象。
  * 怀疑整个 CanvasLayer / Viewport 的根节点坐标或 Camera 偏移计算存在向下偏移。

---

## 2. 窗口重叠与任务面板 (QuestDialog) 异常

### 缺陷描述
* **窗口重叠冲突**：
  * 左上角的 **NPC 对话框**（显示 "I got what you need..." 选项）与下方弹出的 **【任务列表】窗口** 在纵向上发生严重叠压，导致 NPC 选项被掩盖。
* **【任务列表】窗口内部样式失调**：
  * **标题重叠/错位**：顶部标题 “任务列表” 字体与窗口金属框基线不匹配，靠左过于紧凑。
  * **内容列表区黑块**：任务条目列表区域为空白黑块，缺乏占位文字或格式化列表结构。
  * **底部控制区间距异常**：底部 “可接任务” 标签和数量文本框边框尺寸偏小，与底框不匹配。

---

## 3. 底部主控制面板 (MainPanel) 布局与视觉组件缺陷

### 缺陷描述
* **腰带/药水快捷栏 (BeltBar) 渲染遮挡**：
  * 主面板最左侧本应向上延伸或完整显示的药水/腰带快捷格（6格/12格）仅露出顶层极窄的一小截灰色阴影，大部分图标区域被压在主面板下方或未被正常绘制。
* **快捷技能/物品槽 (QuickSlotBar) 缺失**：
  * 主面板中央（HP/MP 血条上方区域）未显示 1~0 / F1~F12 技能与物品快捷插槽边框。
* **攻击/宠物模式文本 (AttackModeLabel / PetModeLabel) 越界**：
  * `Attack: Peaceful` 和 `Pet: Move, Attack` 文本直接越过了主面板底层边框，打印到了游戏地面背景贴图中。
* **属性数值与文本重叠**：
  * `HP 3106/3106` 和 `MP 1381/1381` 数值与左侧 `HP`/`MP` 字母无安全间距。
  * 右侧 `CL`、`LV`、`FP`、`CP`、`AC`、`MAC`、`DC`、`SC` 标签与对应数值排版混乱、缺乏列对齐。

---

## 4. 优化与修复优先级规划

| 序号 | 缺陷分类 | 优先级 | 影响范围 |
| :--- | :--- | :--- | :--- |
| **P0** | **顶部状态栏与视口偏移** | 高 | 导致顶部所有状态 Buff 及坐标信息无法正常显示 |
| **P0** | **主面板 (MainPanel) 腰带栏与快捷槽** | 高 | 玩家无法查看/使用腰带药水和快捷技能槽 |
| **P1** | **UI 窗口层级与重叠管理** | 中 | NPC 对话框与任务窗口重叠，影响正常交互 |
| **P2** | **主面板文本与属性格式化** | 低 | 模式文本越界及 HP/MP 属性对齐优化 |
