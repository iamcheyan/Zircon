# 00 · Zircon 中英对照名词表 · 总目录

> 生成日期: 2026-08-08
> 用途: 为 Zircon（Mir2/Mir3 传奇系）客户端与文档的**中文本地化翻译**提供统一名词基准。翻译前先查本目录，避免一词多译。
> 数据来源: ① 服务端数据库 `System.db`（`/tmp/zircon-server/Database/`）各 Info 表；② 原版官方中文文案 `Client/Envir/Translations/ChineseMessages.cs`；③ 仓库既有译名研究 `docs/notes/22`、`docs/notes/28`；④ 热血传奇 / 传奇3 通行经典译名（网络核实）。

---

## 1. 译名规范（优先级从高到低）

1. **热血传奇（Mir2 盛大官方）经典译名** —— 技能、怪物、地名、武器凡有官方译名者一律采用（火球术、基本剑术、半月弯刀、雷电术、沃玛战士、祖玛教主、比奇城…）。
2. **传奇3（EI 2.0 系）通行译名** —— 本地库为传奇3 后期内容（刺客职业、召唤神兽链、龙渊/冰宫地图等），用传奇3 玩家圈通行叫法（龙影剑法、莲月剑法、铁布衫、幽灵步…）。
3. **意译** —— 无经典译名的原创内容（私服原创武器/怪物/地图），按英文词义准确意译，专有名词音译。
4. **所有条目必须给出确定译名**；确无把握的标注 `【待核】` 并说明理由，禁止编造。

**通用规则**：
- 人名：音译（Mr. Kang → 康先生，沿用原版惯例）；地名沿用 `docs/notes/22` §3.2 已定译名。
- 装备/物品名：意译为主，保留材质/元素/等级词（Serpent Sword → 蛇纹剑）。
- 技能名：动作/效果直译，与经典译名对齐（Slaying → 攻杀剑术）。
- 任务名：意译任务目标，分节序号用中文数字（Pt. 1 → 一）。
- 货币：Gold 金币 / Game Gold 游戏币(GG) / Hunt Gold 狩猎币(HG) / Fame Point 声望点(FP) / Contribution Point 贡献点(CP)。
- 格式：每个条目至少给出「Index / 英文原名 / 中文译名」三列，附必要备注（参考来源或意译说明）。

## 4. 使用说明

- 翻译遇到新英文名词，先在本目录各分册检索；无对应条目时按 §1 规范新译，并回填对应分册。
- 各分册按 Index（数据库主键）排序，方便与 DB/代码对照。
- 修订记录：每次新增/修正译名在分册末尾「修订记录」追加一行（日期 + 改动）。
