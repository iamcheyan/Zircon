# EI 传奇3.0 客户端 vs mir3ei / 当前实现：全量差异报告

> 调查日期: 2026-08-09
> 目标: 梳理 `EI传奇3.0客户端`（2002–2003 早期版本，用户最终要复原的目标）与 `mir3ei`（同源但积累 20 年新内容的客户端）以及 Zircon 当前实现之间的全部差异，作为「裁剪新内容」的依据。
> 数据源:
> 1. `NAS/TMP/EI传奇3.0客户端/` —— 2003 年 EI 客户端本体（544 张地图）
> 2. `NAS/TMP/mir3ei/` —— 同源但含 20 年补丁的客户端（566 张地图）
> 3. `NAS/TMP/Mud3/` —— EI 客户端配套服务端（英雄杀 Mud3，2015 版，用户解压的 7z；Mapinfo/MonGen/Merchant 权威）
> 4. `NAS/TMP/Mud3/Envir/Mon_Def/*.gen` —— 服务端刷怪配置（3221 条）
> 5. `Zircon/docs/database/` —— Zircon 本地数据库导出（244 地图 / 309 怪物 / 125 NPC / 1471 刷怪）
> 6. `Zircon/docs/terminology/` —— 中英对照术语表（13 份）

## 1. 客户端本体差异（EI vs mir3ei）

### 1.1 目录规模

| 项 | EI 客户端 | mir3ei | 差异 |
|---|---|---|---|
| 地图 Map/ | **544** | **566** | +22 |
| Data/ | 182 文件 | 174 文件 | -8 |
| Sound/ | 609 | 761 | +152 |
| 根目录 exe | EI传奇.exe / Mir3.exe / Mir4.exe / Mir3hg.exe | Mir3.exe（仅） | EI 多 3 个 exe |
| 根目录 dll | Ats/Gut/Mirts/MirMg/flyEx/npcipher 等 | Ats/Gut/MirMg/npcipher 等 | EI 多 Mirts/flyEx |

> EI 根目录含 **Mir4.exe**（2011-01-10，刺客扩展版入口）与 **Mir3hg.exe**（2002-12-03）——多版本并存，说明 EI 客户端本体即「早期版 + 后续补丁」混合。

### 1.2 地图差异（忽略大小写）

**EI 独有（4 张，早期地图）：**

| 文件 | 尺寸 | 说明 |
|---|---|---|
| `0_000.map` | 70×70 | 市政厅（术语表代码名 0_000） |
| `31.map` | 300×300 | 大尺寸地图 |
| `50.map` | 120×150 | 中型地图 |
| `50_001.map` | 70×70 | 中型地图 |

**mir3ei 独有（26 张，20 年新增内容）：**

| 文件 | 家族 | 说明 |
|---|---|---|
| `D1500` | 诺玛 | 诺玛地下新增 |
| `D15011–D15014` | 诺玛 | 诺玛地下 1 层四向 |
| `D15021–D15024` | 诺玛 | 诺玛地下 2 层四向 |
| `D15032–D15034` | 诺玛 | 诺玛地下 3 层三向 |
| `D15043–D15044` | 诺玛 | 诺玛地下 4 层两向 |
| `D15054` | 诺玛 | 诺玛地下 5 层 |
| `D1506` / `D1510` / `D15111–D15113` / `D1512` / `D1513` | 诺玛 | 诺玛新增深层 |
| `D9011` / `D9012` / `D903` / `D9033` / `D904` | 赤月 | 赤月山谷新增 |

> 结论：mir3ei 的 20 年新增几乎全部集中在**诺玛地下深层（D1500 系）与赤月山谷（D900 系）**。这 26 张是「裁剪」的首要候选。

### 1.3 同名 540 张地图内容差异

540 张同名地图中，**GameInter.wil 等 25 个同名 .wil 内容不同**（详见 §4 数据文件差异）。地图文件本身多为同名同构（EI 早期 + mir3ei 沿用），但**服务端刷怪配置差异才是内容核心**（见 §2）。

## 2. 服务端配置差异（Mud3 vs Zircon 本地库）

### 2.1 地图体系对比

| 维度 | Mud3 服务端（英雄杀 2015） | Zircon 本地库（System.db） |
|---|---|---|
| 地图数 | 365（Mapinfo.txt） | 244（MapInfo 表） |
| 地图代码 | `01`=边境城市、`02`=银杏山谷、`0`=比奇县 | `0`=Bichon Town、`1`=Lost Paradise |

服务端 365 个地图代码中 **308 个与 EI 客户端 `.map` 文件名直接同名命中**（去掉 `.map` 后缀）。未命中的 57 个多为服务端新增（`D1500 系诺玛深、D1600 系、D2000 系西沙、Island01/02 生存游戏场、NPCRoom1、RUSH1 试练屋、Z013`）——**这些正是服务端后期内容，EI 客户端未包含**。

| 02 | 银杏山谷 | 02.map | 直接命中 |
| 1 | 道馆 | 1.map | 直接命中 |
| 4 | 绿洲 | 4.map | 直接命中 |

## 4. 数据文件差异（EI vs mir3ei 客户端 Data/）

| 文件 | EI 大小 | mir3ei 大小 | 结论 |
|---|---|---|---|
| GameInter.wil | 6,561,945B | 5,446,392B | **内容不同**（EI 更大） |
| 25 个同名 .wil | 各异 | 各异 | **内容不同**（GameInter/Equip/FMMap/Ground/Interface1c 等，详见 HTML 报告数据表） |
| MInfo.dat | 42,152B | 同 | 加密，疑似怪物名表（2003-07-01） |
| Magic.exp | 14,735B | 同 | 魔法扩展 |
| Weapon.ord | 2,640B | 同 | 武器顺序表 |
| CMList.dat | 14,170B | 同 | 加密，2001-09-05 |

> MInfo.dat / CMList.dat / Magic.exp / MExplain.exp 均为**加密二进制**（非明文），无法直接解析出怪物/魔法名单——但服务端 .gen / Mapinfo 已提供权威中文名，无需破解。
