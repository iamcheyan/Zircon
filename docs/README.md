# 文档导航

本目录按“正式项目说明、交接资料、问题与审计、专题研究、数据库资料、历史笔记、网站内容”组织。

## 目录约定

- `project/`：项目架构、运行、迁移和工具使用说明。
- `handoffs/`：长期任务交接、智能体 Prompt、阶段性接手说明。
- `bugs/`：问题分析、复现记录、修复方案和回归报告。
- `research/`：原版客户端逆向、地图、UI、资源和内容调查；机器可读证据也放在这里。
- `database/`：数据库模型和数据字典。
- `notes/`：按时间积累的开发笔记和学习记录。
- `terminology/`：传奇/Mir3 内容术语和百科资料。
- `legacy-atlas/`：百科网站的静态页面。

## 规则

研究结论必须注明来源、坐标系和证据等级（`primary`、`derived`、`candidate`、`pending`）。生成的图片、缓存、下载包和本地客户端继续放在被 `.gitignore` 忽略的 `Debug/`、`Resource/` 或外部 NAS，不提交到仓库。
