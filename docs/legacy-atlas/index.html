裁剪原则

先做 profile 和依赖图，再物理删除。每一项都要能回答：参考包是否有证据？被哪些 packet、数据库表和 UI 引用？

最重要的限定

参考包的日志最晚到 2014 年，且含扩展地图、Gsql 和修改器。它更准确地说是“老版本风格的 Mud3 发行包”，不是纯净的 2003 官方快照。
