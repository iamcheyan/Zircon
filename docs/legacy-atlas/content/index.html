目前最重要的发现

老 Mud3 的内容已经远比“基础三职业 + 几张地图”丰富：Mapinfo 里已经有神舰、赤月、祖玛、矿区、竞技场、行会大战、试练场等内容。因此后续不能把所有高级地图或高级技能都直接算成“20年后新增”，必须逐条对照。
