阅读规则

这部分是资料整理站，不是把“当前存在”直接等同于“20年后新增”。每条老版记录必须能回指 Mud3 原始文件、EI 2.0 资料或已存档图片；无法从老文件可靠读出的项目会明确标记为待解码。

老版 stditem.dat / magic.dat / monster.dat 解码结果已补入各分类页（技能/物品/怪物均有对照表），每条记录带 old-only / current-only / both / changed / unverified 状态；汇总页见 老版 DAT 解码逐条表。
