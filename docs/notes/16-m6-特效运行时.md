# 16 - M6: 通用特效运行时

## 改了什么

M5 的魔法特效只有一个临时占位节点 `EffectNode.cs`（单帧画一张 Magic.Zl 图，500ms 后消失，没有动画）。M6 把它替换成完整的通用特效系统，等价于原版 `Client/Models/MirEffect.cs` + `MirProjectile.cs`。

### 新建两个文件

**`GodotClient/Scripts/MirEffectNode.cs`**（通用序列帧特效节点，Node2D）
- 帧序列：`StartIndex`/`FrameCount`/`Delays[]`（每帧毫秒数）
- 播放控制：`Loop`（循环）、`Reversed`（倒放）、帧播完回调 `CompleteAction`、帧切换回调 `FrameIndexChanged`
- 方向帧：`Skip`（方向间隔，原版默认 10）+ `Direction`（8 方向），画哪帧 = 帧序号 + 起始帧 + 方向 × Skip
- 锚定：跟随目标对象（`_target`）或固定地图格子（`MapCellX/MapCellY` + `_cameraFn` 委托换算屏幕坐标）
- 绘制：`UseOffSet`（用图库每帧自带的 OffSetX/OffSetY 定位）、`Blend`+`BlendRate`（半透明混合）、`Opacity`
- `GetFrame()` 按 Delays 推进，Loop 时对总时长取模，Reversed 反向遍历——逻辑与原版完全一致

**`GodotClient/Scripts/MirProjectileNode.cs`**（飞行物节点，继承 MirEffectNode）
- `Origin`（起点格子）→ 目标（格子或跟随对象）线性插值飞行
- `Direction16`/`Has16Directions`：用原版 `Functions.Direction16/Distance` 算 16 方向帧与飞行时长
- 到达目标自动调 `CompleteAction` 并自删（爆炸特效由回调触发，M10 接）

### 改动

- `GameScene.cs` 的 `SpawnEffectAt` 从 `new EffectNode()` 换成 `new MirEffectNode()`，用 Magic.Zl 真实爆炸帧（580 起 10 帧，Blend 半透明，参考原版火球爆炸 `MirEffect(580, 10, ...)`）
- 删除旧 `EffectNode.cs`（被 MirEffectNode 完全替代）

## 为什么这么做

原版特效是一个通用运行时：施法、受击、Buff、投射物全走同一套 `MirEffect`，只是参数不同（图库/起始帧/帧数/混合率/锚定）。M5 的单帧占位只能看"有特效"这个事实，M10 战斗特效、Buff 特效、怪物投射物都要靠这套运行时。现在地基打好了，后面每个特效只是"填参数"。

关键决策：
- **用真实帧号**：Magic.Zl 有 3580 帧，帧 0 是空白图。原版火球飞行用 420、爆炸用 580、雷电用 10。必须按原版帧号填参数，不能从 0 开始猜。
- **Blend 用 alpha 降**：原版 `DrawBlend` 是加色混合，Godot 先用 `Color(1,1,1,BlendRate)` 降 alpha 近似（Godot 默认 alpha blend），视觉已可用；后续要加色混合再上 `CanvasItemMaterial`。
- **锚定用委托**：`GameScene.ComputeObjectScreenPos` 是私有方法，特效节点通过 `Func<Vector2>` 委托拿到格子→屏幕坐标换算，跟随镜头滚动。

## 怎么验证的

1. `dotnet build GodotClient/ZirconClient.csproj` → 0 error
2. headless 回归：进游戏、添加 20 个物体、0 异常、0 断连
3. 窗口验证（临时代码，验证后删除）：
   - 在玩家上方格 spawn 一个 **Loop 循环**的爆炸特效（帧 580-589，Blend）
   - 同时 spawn 一个 **MirProjectileNode 飞行物**（火球帧 420-424）从玩家右 5 格飞向玩家上方格
   - spawn 后 200ms 游戏内 SavePng 截图，inspect_image 确认：
     - 玩家右上方格有**橙黄色圆形爆炸特效**（中心明亮、边缘不规则波动、底部深色圆形底座，半透明发光感）✅
     - 爆炸特效左前方约 1-1.5 格处有一个**独立的黄白色小光点**（飞行中的火球）✅
     - 玩家角色位置与特效相对关系正确 ✅
4. 临时验证代码全删，`grep FxTest/_dbg` 无残留，`git status --short` 干净

## 遗留

- `MirLineEffect`（弹簧/重力物理链）M6 跳过，后续驯兽/特殊场景需要再补
- 加色混合（Additive Blend）暂用 alpha 降近似，视觉需要时再升级
- 特效的 `DrawType`（Floor/Object/Final 三层 Z 排序）已用 `ZLayer` 字段预留，GameScene 接线时按需设置
