# 24 怪物动作与魔法:AI 行为 → 动作广播 → 动画/特效/弹道渲染

> 承接《23-人物动作系统》。本文聚焦怪物(Monster)侧:服务端如何决策行为(AI int → 行为类)、如何广播动作包、客户端如何把动作翻译成动画/特效/弹道/音效。
> 双端分离要点:**服务端怪物在 `ServerLibrary/Models/MonsterObject.cs`(逻辑/AI),客户端怪物在 `Client/Models/MonsterObject.cs`(动画/特效/音效),两者同名但职责不同**;连接点是 `MagicType`(施法特效联动的唯一键)与 `S.*` 动作包。

### 1.2 Spell 动作的触发链路(关键)

```
服务端 Broadcast S.ObjectMagic{Cast=true, Type=MagicType, Targets/Locations}
  → 客户端 CConnection.cs:1196 ObjectAction(Spell, ..., Type, Targets, Locations, Cast, AttackElement) 入 ActionQueue
    → MapObject.SetAction case Spell(MapObject.cs:768-771):if (!MagicCast) break;  // Cast=false 只播 Combat3 无特效
      → 特效大 switch(MagicType 分支,见 §3) + MirProjectile 弹道
```

`MagicType=(MagicType)action.Extra[0]`、目标列表取自 `Extra[1]`(MapObject.cs:3603-3606)。施法动画播完进入 DelayMagic 结算。

### 4.3 基类 AI 流程(ServerLibrary/Models/MonsterObject.cs)

```
Process(928): 清理死目标
  └─ ProcessAI(≈972):
      ├─ ProcessRegen  回血
      ├─ ProcessSearch 索敌(FindRange/ViewRange/CoolEye 影响)
      ├─ ProcessRoam   闲逛(1184)
      └─ ProcessTarget 攻击决策(1243):
           ├─ Fear 毒 → 逃跑
           ├─ 不在 InAttackRange() → MoveTo 接近
           └─ 在射程内且 CanAttack → Attack()
```

宠物模式(TameTime/UnTame/PetRecall)单独分支。子类通过重写 ProcessTarget/Attack/InAttackRange 实现行为差异。

### 4.4 行动门控(ServerLibrary/Models/MapObject.cs:86-88)

- `CanMove/CanAttack/CanCast`:受 Dead / ActionTime / AttackTime / MagicTime / ShockTime / 麻痹 / 恐惧 / 沉默 / DragonRepulse buff 限制;
- `UpdateAttackTime`(MonsterObject.cs:2354-2358):`AttackTime = Now + AttackDelay;ActionTime = Now + min(MoveDelay, AttackDelay-100)`(MonsterInfo 默认 AttackDelay=2500, MoveDelay=1800)。

## 5. 怪物攻击与施法(服务端)

### 5.1 近战 Attack(≈1689-1705)

转向 → `Broadcast(S.ObjectAttack{Direction, Location})` → `DelayedAction(400ms, DelayAttack, Target, GetDC(), AttackElement)` 延时结算(给客户端播放动画的时间)。

### 5.2 施法四件套(1778-1863)

| 方法 | 行为 | 包 |
|---|---|---|
| `AttackMagic(magic, element, travel, damage=0)` | 单体,MagicRange(Globals.cs:89 = 10 格)内;travel=true 时结算延迟 + 距离×48ms(弹道飞行时间) | S.ObjectMagic{Cast=true, Type, Targets=[Target]} |
| `AttackAoE(radius, magic, element, damage=0)` | 对 Target 位置半径内 `GetTargets` 逐个 DelayAttack | S.ObjectMagic{Cast=true, Type, Locations=[Target]} |
| `SamaGuardianFire()` | 专用于 Sama 火守卫:半径 5 火焰 AoE | S.ObjectMagic{Type=SamaGuardianFire} |
| `LineAoE(distance, min, max, magic, element)` | 八方向扇形直线;LightningBeam/BlowEarth/ElementalHurricane 只填 Locations(无目标逐格),其他魔法逐格加 Locations 且命中即加 Targets | S.ObjectMagic{Cast=true, Type, Targets, Locations} |

统一模式:先 Broadcast S.ObjectMagic(Cast=true) 让全屏播放施法动画,再按(距离/方向)排 DelayedAction 结算伤害。

### 5.3 场地魔法(1959-2326)

FireWall(十字火墙 + DelayMagic 结束)、MassLightningBall(2070)、MassThunderBolt(2107)、MassCyclone(2224)、PoisonousCloud(2288,毒云 SpellObject Power=20)。ProcessAction(900-930)统一处理 DelayAttack/DelayMagic 结算。

### 5.4 死亡/受击

- 受击:`Attack(mapObject, power, element)` 精度 vs 敏捷、元素 vs 魔防、Abyss 毒闪避;BOSS(DoomClaw)重写 Pushed 返回 0 免疫击退;
- Die(2505):base.Die + YieldReward(掉落)、清 Master/MinionList/PetOwner、`DeadTime = Now + DeadDuration(+HarvestDuration)` → 由此决定 S.ObjectDied 广播时机。

## 10. 一图总结:怪物动作全流程

```
MonsterInfo.AI(int) → GetMonster 工厂(122-647) → 行为子类
  → Process → ProcessAI → ProcessSearch/Roam/Target
      ├─ 近战: S.ObjectAttack → 客户端 Combat1
      ├─ 远程: S.ObjectRangeAttack{Targets} → Combat2 + CreateProjectile
      ├─ 施法: S.ObjectMagic{Cast=true, Type, Targets/Locations} → Combat3 + MagicType 特效/弹道
      ├─ 移动: S.ObjectMove → Walking
      ├─ 被击: S.ObjectStruck → Struck
      ├─ 死亡: S.ObjectDied → Die(10 帧)→ Dead/Skeleton
      └─ 现身/隐: S.ObjectShow/S.ObjectHide → Show/Hide
```

**一句话:服务端 AI(int)+ 子类重写决定"做什么",S.* 动作包广播"做了什么",客户端按 MirAction→MirAnimation→FrameSet→Mon_XX 图集逐帧还原,MagicType 是施法特效的唯一联动键。**
