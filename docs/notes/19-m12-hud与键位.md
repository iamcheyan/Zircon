# M12: HUD + 键位系统

## 目标

移植游戏内 HUD（底部 MainPanel、右上小地图、Buff 栏、任务追踪）、键位绑定系统（KeyBindManager）、大地图窗口，并将 M11 窗口框架接入真实游戏数据流（ServerConnection 事件 → GameScene 集成）。

## 交付内容

### 1. KeyBindManager.cs（新）

原版 `Client/Envir/CEnvir.cs` 键位表移植：

- `KeyBindAction` 11 项：MenuWindow(N) / HelpWindow(H) / ConfigWindow(O) / CharacterWindow(Q) / InventoryWindow(W) / MagicWindow(E) / QuestTrackerWindow(L) / MapMiniWindow(V) / MapBigWindow(B) / ChangeAttackMode(Ctrl+H) / ChangePetMode(Ctrl+A)。
- `GetAction(InputEventKey)`：匹配按键 + 修饰键（Ctrl/Alt/Shift）。
- `GetKeyBindLabel`：显示 "Ctrl + H" 格式。

### 2. 事件总线扩展（ServerConnection.cs）

按原版 `CConnection` 语义新增事件与 Pending 队列：

- 状态类：`StatsUpdateEvent`（签名改为完整 `S.StatsUpdate`）、`LevelChangedEvent`、`GainedExperienceEvent(decimal)`、`InformMaxExperienceEvent(decimal)`、`ManaChangedEvent(uint,int)`、`FocusChangedEvent(uint,int)`。
- Buff 族：`BuffAddEvent(S.BuffAdd)` / `BuffRemoveEvent(int)` / `BuffChangedEvent(S.BuffChanged)` / `BuffTimeEvent(S.BuffTime)` / `BuffPausedEvent(int,bool)`。
- 模式回显：`AttackModeChangedEvent(AttackMode)` / `PetModeChangedEvent(PetMode)`（原版 CConnection:3749-3760 设 `User.AttackMode/PetMode = p.Mode`，服务端回显权威）。
- 对应 Pending 队列 + Process 统一 Enqueue + Invoke。

### 3. GameScene.cs 集成

- `CreateHud()`：MainPanel 底中、MiniMap 右上 (W-200,0)、QuestTracker (W-250,205)、Buff (W-200-BuffW-5,0)、BigMap 居中；**DXWindow 默认 Visible=false，HUD 常驻窗口显式置 Visible=true**。
- `InitHudData(StartInformation)`：Level/Class/Exp/HP/MP/FP/AttackMode/PetMode + Buffs + QuestTracker.PopulateQuests；**MaxExperience 不重置**（登录期 InformMaxExperience 排空先到）。
- 事件处理器：OnStatsUpdate 存完整 Stats；OnLevelChanged/OnGainedExperience/OnInformMaxExperience/OnManaChanged/OnFocusChanged（后两者 ObjectID 须=玩家）；OnBuff* 维护 `_buffs` 字典（Key=Index）→ BuffsChanged。
- 模式循环：`CycleAttackMode/CyclePetMode` 本地 (mode+1)%5 + Enqueue `C.ChangeAttackMode/PetMode`，回显事件再设一次（双保险，照原版）。
- `_Input`：F2/Esc 保留 → `KeyBindManager.GetAction(key)` → `HandleKeyBind`（V/B 切图、L 任务追踪、Ctrl+H/A 模式循环；N/H/O/Q/W/E 对话框留后续里程碑，no-op 打印）。
- 地图数据：`LoadPlayerMap`/`AddObject`/`OnObjectRemove`/`ShowUserLocation`/`OnObjectStruck` 玩家与物体更新转发到小/大地图。
- 血量：`OnHealthChanged`/`OnDataObjectHealthMana` 玩家分支 → `_currentHP = _player.Health` + SetHealth。

### 4. 小/大地图 API 解耦

`UpdateObject(uint objectID, int cellX, int cellY, ObjectRenderer.Kind kind)` + `UpdatePlayer(int cellX, int cellY)`，不依赖 PlayerRenderer/ObjectRenderer 具体类型（PlayerRenderer 非 ObjectRenderer 子类导致 CS1503）。

### 5. MainPanel / BuffDialog / QuestTrackerDialog / BigMapDialog / DXVScrollBar / DXMapInfoControl（新）

- MainPanel：底图 50 + HP/MP/FP 条 + 经验条 + 职业属性文字 + 类按钮；百分比填充 = 原版"缩放"语义（目标 rect 宽 = image.Width × percent，DrawTextureRect）。
- 血/蓝/专注条填充纹理 52/54/58（满值闪 glow 59），经验条填充 56。
- BuffDialog：CBIcons.Zl 图标网格 + BuffsChanged 全量刷新；空时自动隐藏。
- QuestTrackerDialog：无标题边框、悬停半透明（Opacity 0→0.3，原版语义）、滚动条。
- BigMapDialog：居中显示当前地图、Recent/Recenter（仅非当前图 Enabled，点击切回当前地图）。

## 关键 Bug 修复

- **条填充坐标**：`DrawBarFill`/`DrawExperienceFill` 原在 MainPanel 上调用 `DrawTextureRect`（`this`=MainPanel），但事件来自 bar 控件绘制 → 报错 "Drawing is only allowed inside this node's _draw()" 且填充画到面板左上角。修复：改为在 bar 控件上绘制（`bar.DrawTextureRect`）。
- **HUD 窗口不可见**：DXWindow 构造默认 `Visible=false`（沿用原版窗口管理语义），常驻 HUD 窗口（小地图/任务/Buff）显式置 true。
- **PlayerRenderer 类型不匹配**：地图 API 改收 cellX/cellY/kind。
