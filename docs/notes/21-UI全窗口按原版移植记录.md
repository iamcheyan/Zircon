## 第1步: CharacterDialog 人物纸娃娃 (完成)

**对照原版**: `Client/Scenes/Views/CharacterDialog.cs:2555-2700` `CharacterTab_BeforeChildrenDraw`

**实现**: 新增 `GodotClient/Controls/PaperDoll.cs` (146 行), 作为 Control 嵌入 CharacterDialog。
- 绘制顺序: ProgUse[刺客女发型] → ProgUse[0男/1女裸身] → Equip[衣服/时装+overlay染色] → Equip[武器+overlay] → Equip[盾+overlay] → Equip[头盔+overlay]
- 坐标: 原版 (130,270) 相对 CharacterTab; 我们窗口 (130,251) (减标题栏19)
- 数据源: `GameScene.StartInfo` (Gender/Class/HairType/HairColour/Horse) + `GameScene.Equipment`
- 骑马 (Horse!=None): HideBody+HideWeapon, 只露头

**接入**: `CharacterDialog` 构造里 bg 之后 AddChild(doll), doll.Position=(130,251)

**简化**: 暂未实现 Fame特效、装备光效(EquipEffectDecider)、行会旗帜、Inspect 远程查看; overlay 染色用半透明重画近似 (ZlReader 未分离 Overlay 帧)

**坑**: PaperDoll 是 Control 不是 DXControl, 不能用 AddControl (类型不符), 用 AddChild; Position 在 CharacterDialog 外部设置覆盖构造默认; ZlLibrary 在 ZirconClient.Formats 命名空间需 using

**验证**: 编译 0 错误 (运行视觉验证待用户)

## 第2步: 技能系统完整性修复 (3个问题)

### 问题1: 进游戏已有技能没加载 (严重, 导致技能完全不能用)
**根因**: StartInformation 包自带 Magics 字段 (List<ClientUserMagic>), 服务端 GetStartInformation 把 Character.Magics 全塞进去 (PlayerObject.cs:857)。但 GameScene.InitHudData 只处理了 Buffs/Items/Currencies/Storage, 漏了 Magics。S.NewMagic 只在"学新技能"时发, 初始技能靠 StartInfo。
**修法**: GameScene.InitHudData 加 foreach 填 UserMagics (含 Complete() 补 Info 绑定) + 刷新 MagicBar/MagicDialog。

### 问题2: 魔法特效是统一占位 (严重, 所有魔法看起来一样)
**根因**: OnObjectMagic 对所有魔法播同一个 MirAnimation.Combat1 + 同一个 Magic.Zl[580] 爆炸。原版 MapObject.cs:768 是 174 个 case, 每个魔法不同的图库/帧/颜色/弹道。
**修法**: 新增 MagicEffectTable.cs (~30 个常见技能的特效定义: 图库/起始帧/帧数/速度/颜色/弹道/落地)。OnObjectMagic 改为查表播放: 站桩特效 + 弹道 + 落地。查不到回落通用爆炸。
- 颜色用原版 Globals.*Colour 近似 (Fire/Ice/Lightning/Wind/Holy/Dark/Phantom/None)
- 覆盖: 战士5个 + 法师14个 + 道士9个 + 刺客1个 = ~29个常见技能
- 未覆盖的 174-29=145 个技能用通用爆炸兜底 (不报错, 只是视觉不精确)

### 问题3: 飞行弹道缺失 (中等)
**根因**: 原版火球/冰箭是 MirProjectile (施法者→目标飞行+拖尾), 我们只有站桩 MirEffect。
**修法**: OnObjectMagic 里 def.Projectile 非空时用 MirProjectileNode.SetupProjectile, origin=施法者格, target=目标格, 到达后 CompleteAction 播落地特效。
