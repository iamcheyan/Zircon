## 1. 快捷键系统(KeyBindAction)

### 1.1 枚举定义

`Client/UserModels/KeyBindInfo.cs:162` `public enum KeyBindAction`,按功能分四组:

**A. 窗口开关(24)**

ConfigWindow(设置)/ CharacterWindow(角色)/ InventoryWindow(背包)/ MagicWindow(技能列表)/ MagicBarWindow(技能栏)/ RankingWindow(排行)/ GameStoreWindow(商城)/ DungeonFinderWindow(副本匹配)/ CompanionWindow(伴侣)/ GroupWindow(队伍)/ AutoPotionWindow(自动药水)/ StorageWindow(仓库)/ BlockListWindow(黑名单)/ GuildWindow(行会)/ QuestLogWindow(任务日志)/ QuestTrackerWindow(任务追踪)/ BeltWindow(腰带)/ MapMiniWindow(小地图)/ MapBigWindow(大地图)/ MailBoxWindow(邮箱)/ MailSendWindow(写信)/ ChatOptionsWindow(聊天设置)/ ExitGameWindow(退出)/ FortuneWindow(运势)/ CurrencyWindow(货币)。

**B. 模式切换与功能(9)**

ChangeAttackMode(攻击模式)/ ChangePetMode(宠物模式)/ GroupAllowSwitch(允许组队)/ GroupTarget(把目标拉进队伍)/ TradeRequest(请求交易)/ TradeAllowSwitch(允许交易)/ ItemPickUp(拾取)/ PartnerTeleport(婚戒传送)/ MountToggle(上/下马)/ AutoRunToggle(自动跑步)/ ChangeChatMode(切换聊天频道)/ ToggleItemLock(物品锁定)。

**C. 腰带快捷用药(10)**

UseBelt01-10:对应腰带 10 格,直接使用绑定的药水/物品(发 C.ItemUse 或 C.BeltLinkChanged 绑定)。

**D. 技能栏(28)**

SpellSet01-04(4 套技能栏切换)+ SpellUse01-24(每栏 24 格施法)。

### 1.2 键位分发入口(GameScene.OnKeyDown:1218,switch 体 1236-1655)

游戏主循环 Process 中检查按键 → `switch (keyBindAction)`:

```
case KeyBindAction.ConfigWindow:    if (Observer) continue; ToggleWindow(...); break;   // 各窗口同模式
case KeyBindAction.ChangeAttackMode: 发 C.ChangeAttackMode(服务端记录攻击模式)         // 1344
case KeyBindAction.ChangePetMode:    发 C.ChangePetMode
case KeyBindAction.MountToggle:      if (Horse == None) 发 C.Mount; else 下马          // 1389
case KeyBindAction.AutoRunToggle:    切换 AutoRun;发 GameSceneAutoRunOn/Off(本地)      // 1398
case KeyBindAction.UseBelt01-10:     UseBeltItem(槽位)(发 C.ItemUse 链)               // 1403-1521
case KeyBindAction.SpellSet01-04:    切换当前技能栏(本地 UI 状态)                       // 1522-1534
case KeyBindAction.SpellUse01-24:    UseMagic(SpellKey.Spell01..24)(若 Observer 跳过)  // 1535-1655
```

**要点**:
- 窗口开关、技能栏切换、自动跑步是**纯本地 UI 状态**(不发包);
- 施法/用药/上马/模式切换要**发 C.* 包**,服务端校验后才生效;
- `ShiftOpenChat`(GameScene.cs:1405 附近):Shift 键兼作"强制攻击"与"呼出聊天",有状态机避免误触发。

## 2. 鼠标交互扩展(MapControl)

### 2.1 左键(ProcessInput,MapControl.cs:900-1012)

优先级从高到低:

| 条件 | 行为 |
|---|---|
| Shift 且无锁定目标 | 强制近战攻击(无视目标归属,距离==1 + 无马 + 过 AttackTime)→ AttemptAction(Attack) |
| Alt 且武器=鱼竿(ItemEffect.FishingRod)+ 铠甲=鱼袍(FishingRobe) | 钓鱼:FishingZone 合法 + ValidFishingDistance → FishingState=Cast |
| Alt 且武器=驯马索(TamingLasso)+ 目标怪物 AI==135(被动野马)且距离≤TamingDistance(9) | 驯马:TamingState=Cast |
| Alt 其他 | 采集:AttemptAction(Harvest) |
| 钓鱼/驯马进行中 | 取消(State=Cancel) |
| 点在自身脚下 | 拾取:C.PickUp(250ms 节流)→ PickUpTime |
| 鼠标目标是怪物/玩家(非物品、非死) | break → 外层攻击判定(§23-3.4) |
| 地图可挖矿(CanMine)+ 武器=十字镐(PickAxe)+ 点中矿格(Flag) | Mining=true(进入挖矿状态机) |
| 目标格不可走 | 转向 Standing(若方向不同) |
| 可走 | Moving:MoveFrame 门控 + WraithGrip 毒禁止 → AttemptAction(Moving, 距离1) |

### 2.2 右键(ProcessInput,MapControl.cs:1012-1035)

| 条件 | 行为 |
|---|---|
| 钓鱼/驯马进行中 | 取消 |
| Ctrl 且目标是玩家(非自己) | 不移动(防误追人) |
| 距离≤2 | 转向 Standing |
| 其他 | Run(direction)——按住右键持续移动(每 MoveFrame 发 C.Move,距离 1;CanRun 状态下距离 2 跑步) |

### 2.3 挖矿状态机(Mining,1053 后)

```
条件:MapInfo.CanMine + 武器=十字镐 + 矿点格 Flag + 距离==1 + 无马
  → 持续 AttemptAction(Mining) → C.Mining{Direction}
    → 服务端校验矿点 → 产出矿石(带 Mining Effect 特效, S.ObjectMining 广播)
```

### 2.4 腰带格/自动药水格点击(OnMouseDown,589)

- 左键点腰带格(DXItemCell)→ 发 `C.BeltLinkChanged`(把背包物品绑到腰带槽/解绑);
- 左键点自动药水格 → 切换 AutoPotionBox 开关。

## 3. 自动寻路(AutoPath)

### 3.1 协议四件套

| C.* | 用途 | 服务端处理 |
|---|---|---|
| C.AutoPathStart | 开始寻路(带 NPCIndex,常用于"自动走到 NPC 处") | SConnection.cs:441 |
| C.AutoPathWaypoint | 逐点上报途经点(MapIndex, Location) | SConnection.cs:454 |
| C.AutoPathCancel | 取消寻路(空) | SConnection.cs:461 |
| C.AutoPathMoveStarted | 寻路移动开始(空) | SConnection.cs:467 |

服务端返回 `S.AutoPathChanged{Routes: List<AutoPathRoute>}`(ServerPackets.cs:9)同步路线;路径计算在客户端,逐途经点发 `C.AutoPathWaypoint`,服务端逐格校验碰撞(复用 Move 的 IsBlocking 逻辑)。

### 3.2 客户端表现

- `AutoPathRouteControl.cs`(Client/Scenes/Views/):DXControl 子类,`SetRoute(AutoPathRoute, active, displayedMap, currentMap, scaleX, scaleY)` 画路线,`SetProgress(mapIndex, pointIndex)` 更新进度;
- 手动操作(点鼠标/攻击/施法)→ `CancelAutoPath()`(MapControl.cs:596 附近)打断寻路;
- 自动寻路期间移动距离=1(走)或按跑步节奏加速,移动仍走标准 `C.Move` 包。

## 4. 钓鱼小游戏

### 4.1 协议

- `C.FishingCast{State, Direction, FloatLocation, CaughtFish}`(ClientPackets.cs:122):Cast 抛竿 / Catch 收线(带捕获鱼);
- `S.ObjectFishing{ObjectID, State, Direction, FloatLocation, FishFound}`(ServerPackets.cs:121):广播给全视野;
- `S.FishingStats{CanAutoCast, CurrentPoints, ThrowQuality, RequiredPoints, MovementSpeed, RequiredAccuracy}`(ServerPackets.cs:129):**钓鱼小游戏的动态参数**,UI 据此做"鱼漂对齐/连点收线"的判定。

### 4.2 客户端状态机(MapControl)

```
FishingState: None → Cast(Alt+左键抛竿,需 FishingZone + ValidFishingDistance)
  → Wait(浮漂) → (FishFound 时) Catch(收线,连点)
  → None / Cancel(左/右键打断)
```

- 鱼漂位置 FloatLocation 与距离合法性由 `Functions.FishingZone(Globals.FishingInfoList, ...)` 校验;
- 抛竿距离上限 = `User.Stats[Stat.ThrowDistance]`;
- FishingDialog(Client/Scenes/Views/FishingDialog.cs)承载小游戏 UI。

## 5. 驯马

### 5.1 协议

- `C.Taming{State, ObjectID, Direction}`(ClientPackets.cs:130):Cast 开始驯服;
- `C.TamingSuccess{ObjectID}`(137):服务端判定成功后确认;
- `S.ObjectTaming{State, TamingObjectID}`(ServerPackets.cs:139):仅发给驯兽玩家(其他玩家看不到驯服过程);
- 服务端驯服条件:目标怪物 `MonsterInfo.AI == 135`(被动野马)+ 距离 ≤ TamingDistance(Globals.cs:92 = 9)。

### 5.2 客户端状态机(MapControl)

```
TamingState: None → Cast(Alt+左键点 AI==135 野马)
  → Wait(读条) → Success(发 C.TamingSuccess)→ 成为宠物(PetOwner=自己)
  → None / Cancel(左/右键打断)
```

- `HorseTameDialog`(Client/Scenes/Views/HorseTameDialog.cs)显示读条;
- 成功后服务端改 `PetOwner`,广播 `S.ObjectPetOwnerChanged`,客户端马匹归玩家,之后可 `MountToggle` 上马。

## 8. 交互设计要点总结

1. **本地优先**:窗口开关、技能栏切换、自动跑步、寻路路径计算都是客户端本地状态,不发包;服务端只校验"有后果"的动作(攻击/移动/施法/采集/交易);
2. **Shift 键复用**:强制攻击 vs 呼出聊天,靠目标有无 + 按键时序区分;
3. **Alt 键复用**:采集 / 钓鱼 / 驯马,靠武器(鱼竿/驯马索/无)与目标(AI==135)区分;
4. **Ctrl 键修饰**:右键+Ctrl 不追玩家(防误操作);
5. **双端门控**:钓鱼/驯马/挖矿在客户端有状态机(防止重复触发),服务端有独立校验(目标合法性/距离/装备),两者都过才算成功;
6. **节流无处不在**:拾取 250ms、移动 600ms/格、攻击 800ms 起、魔法 2s——客户端先节流,服务端再按 AttackTime/NextMagicTime 二次门控,协议只传"意图+方向+目标",不传动画状态。
