# 35：客户端窗口模式与 --window 参数

2026-08-09。需求：确认 Godot 客户端支持窗口模式，并加一个参数，用该参数运行时**直接显示窗口**，缩放自动调整。

## 现状结论：窗口模式原本就支持，但默认是全屏

- `GodotClient/project.godot`：`window/size/mode=0`（窗口模式）、viewport 1024x768。
- `ClientSettings.ApplyDisplaySettings()`（`GodotClient/Scripts/ClientSettings.cs:241`）有完整的分支：`FullScreen` 时全屏，否则 `WindowSetMode(Windowed)` + `WindowSetSize(GameSize)`。
- **但 `ClientSettings.FullScreen` 默认值是 `true`**（`ClientSettings.cs:33`），`Zircon.ini`（`user://Zircon.ini`）不写该键时直接跑就是全屏——这就是"有没有窗口模式"疑问的来源。
- 窗口化运行已被证实可行：`/tmp/godot_v3.log` 记录了 Vulkan（Apple M1 Max）+ 完整登录进游戏的窗口化会话。

## 缩放机制（自动，无需手工）

`GameScene.RefreshUiScale()`（`GodotClient/Scripts/GameScene.cs:4381`）：

```csharp
UiScale = viewport.Y > 0 ? Mathf.Clamp(viewport.Y / UiScaleBaseHeight, 1f, 2f) : 2f;
```

- 基准逻辑高恒 768（原版 1024x768 窗口）。窗口高度 768 → 1x，≥1536 → 2x（上限，`f5a333a` 固定 HUD 两倍逻辑像素；`bb6e387` 起随窗口等比放大）。
- 所有 UI 布局用 `GetViewport().GetVisibleRect().Size / UiScale` 计算逻辑坐标，任意窗口尺寸下 UI/字体占屏比例与 1024x768 原版一致；窗口放大只扩展可视地图。
- 窗口尺寸变化由 `OnGameResized`（`GameScene.cs:4369`）触发 `RefreshUiScale` + `LayoutHud` 实时重排。

## --window 参数（本次新增）

`GodotClient/Scripts/AutoLoginArgs.cs:42`：

```
godot-mono --path /home/tetsuya/development/Zircon/GodotClient -- --user test@test.com --pass test123 --char TestHero --window
```

- `--window`：强制窗口模式，覆盖 `Zircon.ini` 的全屏/无边框设置（`FullScreen=false, Borderless=false`）。
- 可选分辨率：`--window=1600x900` 或 `--window 1600x900`；缺省按**主屏幕 75%** 计算，夹在 1024x768（最小）与 1920x1080（最大）之间，保证 UiScale 落在 1..2 区间。
- 实现：`ClientSettings.ApplyDisplaySettings()`（`ClientSettings.cs:241`）开头，`AutoLoginArgs.Window` 为真时先改写 `FullScreen/Borderless/GameSize`，再走原有窗口设置流程。三个场景（LoginScene/SelectScene/GameScene 的 `_Ready`）都会调用 `ApplyDisplaySettings`，故登录页起即为窗口。
- headless 运行不受影响：`ApplyDisplaySettings` 对 `DisplayServer.GetName() == "headless"` 直接返回（窗口相关调用跳过），参数解析仍打印诊断 `[Display] --window 强制窗口模式: WxH`。

## 验证记录（2026-08-09）

headless 实测三种形态：

1. `--window=1600x900` → `[Display] --window 强制窗口模式: 1600x900`，StartGame 成功进游戏。
2. 裸 `--window` → `1024x768`（headless 无屏幕可取，保留 ini 默认尺寸；真实窗口下会取屏幕 75%）。
3. 无参数回归 → 无 `[Display]` 打印，StartGame 正常（未改变默认全屏行为）。

真实窗口化显示需用户本机实测确认（本机 headless 无法开窗）。
