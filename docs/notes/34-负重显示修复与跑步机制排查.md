# 34：负重显示修复与跑步机制排查

2026-08-09。用户反馈"当前人物是不是超重了？为什么又不能跑步了？"。排查结论：**人物完全不超重，跑步逻辑正常**，所谓"超重"是角色面板负重上限被写死为 0 的显示 bug，已修复（commit `35bef3b`）。

## 排查过程

### 1. 数据层：查库存与装备实际重量

`Tools/CharacterEditor list`（`Tools/CharacterEditor/Program.cs`）输出 TestHero 背包 68 项物品、14 件装备，逐项 `重量` 求和：背包 266（客户端实测为 225，见下）、装备约 99。

### 2. 上限公式：BaseStat 等级表 + 坐骑加成

- `PlayerObject.AddBaseStats`（`ServerLibrary/Models/PlayerObject.cs:2446`）：`Stats[Stat.BagWeight] = stat.BagWeight` 等，上限来自 `BaseStat` 表。
- 坐骑加成（`PlayerObject.cs:2110` 起）：Brown +50 / White +100 / Red +150 / Black +200 / Unicorn +250。
- `LibraryCore/Stat.cs:688` 定义 `Stat.BagWeight` 枚举。
- 实测（`CharacterEditor basestat --class Taoist`）：**70 级道士 BagWeight=1275、WearWeight=113**（`LibraryCore/SystemModels/BaseStat.cs:69`）。

### 3. 服务端实测：连线上服务器探包

用 `/tmp/GmVerify`（复用 BotRunner 的 `BotConnection`）登录后打印 `S.StatsUpdate` 与 `S.WeightUpdate`：

```
[S] StatsUpdate BagW=1275 WearW=124 HandW=140 HP=3606
[S] WeightUpdate bag=225 wear=42 hand=41
```

| 项目 | 实际 | 上限 |
|---|---|---|
| 背包 | 225 | 1275 |
| 穿戴 | 42 | 124 |
| 手持 | 41 | 140 |

任何维度都不超。服务端 `SConnection.Process(C.Move)`（`ServerLibrary/Envir/SConnection.cs:427`）中的负重拒绝逻辑本就被注释掉（433 行），服务端从不拒绝跑步移动。主动发 `C.Move Distance=2` 实测：服务端回 `S.ObjectMove` 确认，无 `S.UserLocation` 纠正。

### 4. 客户端实测：headless 真实客户端复现

- `--test-right-run`：右键按住 → 连续两段 `distance=2 running=True`。
- `--test-running`：第一段走 1 格（`canRun=False`）→ 收到移动回包后 `canRun=True`，第二段跑 2 格。日志 `bag=225/1275 wear=42/124` 不超重。

### 5. 根因：角色面板负重上限写死为 0

`GodotClient/Controls/CharacterDialog.cs:684` `SetWeight`：

```csharp
// 修复前
WeightLabel.Text = $"负重 {wearWeight} / 手持 {handWeight}";
_wearWeightValue.Text = $"{wearWeight} / 0";   // 上限写死 0
_handWeightValue.Text = $"{handWeight} / 0";   // 上限写死 0
```

`S.WeightUpdate` 到达时（`GameScene.OnWeightUpdate` → `_characterDialog.SetWeight`）覆盖了 `RefreshStatsPanel`（`CharacterDialog.cs:639` 起）的正确显示（`42 / 124`），变成 `42 / 0` → 用户打开角色面板看到"42 / 0"误以为超重。

## 修复

`CharacterDialog.SetWeight` 改为从 `GameScene.Game.PlayerStats` 取真实上限：

```csharp
var stats = GameScene.Game?.PlayerStats;
int wearMax = stats?[Stat.WearWeight] ?? 0;
int handMax = stats?[Stat.HandWeight] ?? 0;
if (_wearWeightValue != null) _wearWeightValue.Text = $"{wearWeight} / {wearMax}";
if (_handWeightValue != null) _handWeightValue.Text = $"{handWeight} / {handMax}";
```

- 提交：`35bef3b`（仅 `GodotClient/Controls/CharacterDialog.cs`，+7 -2），已推送 fork。
- 验证：全量重建 0 错误；headless `--test-right-run` 复验通过。

## 跑步机制备忘（原版规则，非 bug）

客户端 `GameScene.GetRunSteps()`（`GodotClient/Scripts/GameScene.cs:7157`）：

```csharp
int steps = Godot.Time.GetTicksMsec() >= _runCooldownUntilMs
    && _canRun && BagWeight <= _playerStats[Stat.BagWeight]
    && WearWeight <= _playerStats[Stat.WearWeight] ? 2 : 1;
```

1. **站立后第一段必须先走一格**（`_canRun` 仅在收到移动回包/发出移动后才为 true），按住右键不松，第二段才升级为跑步——这是原版设计（`GameScene.cs:788` 注释）。
2. **点按右键（点一下松一下）每段都是走一格**，看起来像"不能跑步"，属正常。
3. 被击中（`_canRun = false` + 600ms 冷却，`GameScene.cs:4105`）后需重新起步。
4. 背包/穿戴任一项超重时只能走一格（`GetRunSteps` 判断），负重数据源见上表。
