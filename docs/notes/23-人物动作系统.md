# 23 人物动作系统:输入 → 动作 → 发包 → 广播 → 动画渲染全链路

> 调研对象:`~/development/Zircon`(C# 传奇类 MMORPG,客户端 `Client/` + 服务端 `ServerLibrary/` + 公共库 `LibraryCore/`)。
> 本文覆盖玩家(人物)从键鼠输入到屏幕动画的完整动作链路:输入捕获 → 动作构造 → 客户端发包(C.*) → 服务端校验与广播(S.*) → 客户端收包 → 动作队列 → 动画帧推进。

---

## 1. 总览:一条动作的完整旅程

以"鼠标左键点相邻怪物攻击"为例:

```
MapControl.OnMouseDown/OnMouseClick        输入捕获(Client/Scenes/Views/MapControl.cs:589/750)
  └─ MapControl.ProcessInput               动作决策(860-1129):距离==1 + 无马 + (无主或Shift) → AttemptAction
       └─ UserObject.AttemptAction         动作构造(Client/Models/UserObject.cs:447):被动技能合并 + SetAction
            └─ CEnvir.Enqueue(new C.Attack) 客户端发包(C.Attack{Direction, Action, AttackMagic})
                 └─ SConnection.Process(C.Attack)  服务端收包(ServerLibrary/Envir/SConnection.cs:411 起,共 152 个 C.* 处理器)
                      └─ PlayerObject.Attack()      服务端校验/结算(ServerLibrary/Models/PlayerObject.cs:14630)
                           └─ Broadcast(new S.ObjectAttack)  服务端广播(带 Direction/Location/AttackMagic/AttackElement)
                                └─ CConnection.Process(S.ObjectAttack)  客户端收包(Client/Envir/CConnection.cs:1254)
                                     └─ MapObject.ActionQueue 入队(ObjectAction)
                                          └─ MapObject.SetAction → PlayerObject.SetAnimation  动作→动画
                                               └─ FrameSet 帧表 + CurrentFrame.GetFrame 逐帧推进 → 渲染
```

**关键结论:输入总入口是 `MapControl.ProcessInput()`,不是游戏主循环;游戏主循环只负责逐帧推进已入队的动作。**

### 2.1 MirAction(动作,`LibraryCore/Enum.cs:463`)

这是**两端共用的动作码**:客户端 `AttemptAction` 构造的动作、`C.*` 包里携带的动作、服务端广播的 `S.ObjectAttack{Direction, Action}`、客户端收包后塞进 `ActionQueue` 的 `ObjectAction(MirAction.X, ...)` 全部用同一枚举。

### 2.2 MirAnimation(动画,`LibraryCore/Enum.cs:488`)

## 3. 输入捕获(MapControl)

`Client/Scenes/Views/MapControl.cs` 是游戏画面控件,所有鼠标输入在此转成"动作意图"。

### 3.1 鼠标状态

- `MapControl.cs:151` `public MouseButtons MapButtons` —— 当前按下的鼠标键集合(ProcessInput 每帧读取)。
- `Config.RightClickDeTarget` —— 配置项:右键是否清除当前怪物目标(OnMouseDown 中处理)。

### 3.2 OnMouseDown(MapControl.cs:589)

- 观战模式(Observer)→ 直接 return。
- 左/右键按下 → `CancelAutoPath()`(手动操作打断自动寻路)。
- 右键 → 若 `Config.RightClickDeTarget` 为 true → 清除怪物目标(`GameScene.Game.TargetObject = null` 等)。
- 左键落在腰带快捷格(DXItemCell)→ 发 `C.BeltLinkChanged`(绑定/解绑腰带物品);落在自动药水格 → 切换 AutoPotionBox。

### 3.3 OnMouseDown 按住攻击 / OnMouseClick 兜底(MapControl.cs:589-744 / 750)

- **OnMouseDown(589-744)**:除前面列出的行为外,还处理"按住左键持续攻击"——若锁定目标(非物品/非死)且过 `User.AttackTime`,直接 `AttemptAction(RangeAttack)`(711 附近,远程/远程怪用);
- **OnMouseClick(750)**:鼠标点击释放后的兜底——`ProcessInput` 已按 `MapButtons` 决策动作;若没有有效动作,OnMouseClick 里按"点地/点怪/点物品"处理(移动或拾取)。

### 3.4 ProcessInput 主流程(MapControl.cs:860-1129,输入总入口)

```
1. 守卫:User.Dead / (麻痹) / (定身 Containment) / DragonRepulse buff → 直接 return
2. 魔法待机:若正在等魔法(NextActionTime 未到 / ActionQueue 非空)→ 先处理魔法后 AttemptAction
3. ElementalHurricane buff 检查(施法中被定身则中断)
4. 目标攻击判定(近战自动攻击):
    条件 = CanAttackTarget(MouseObject/MagicObject) 且 距离==1 且 Now>AttackTime 且 无马
        且 (怪物无 PetOwner 或 按下 Shift)
    → AttemptAction(Attack, 方向, 位置, 0 远程目标ID, None, None)
5. AutoRun → 按鼠标方向跑(MouseDirection() 取最优方向)
6. MapButtons switch:
    Left:    Attack(916)     —— 攻击
    Alt+Left: Harvest(957)  —— 采集
    Right:   Standing(1004) —— 转向;Moving(1012) —— 移动(按住右键跑)
    Ctrl+Left: Mining(?)    —— 挖矿
    Fishing(1085) / Taming(1102) —— 钓鱼 / 驯马(带 FishingState/TamingState 状态机)
```

### 3.5 近战自动攻击的判定条件(核心)

`GameScene.cs:3457` `private bool CanAttackTarget(MapObject ob)` 与 ProcessInput 第 4 步结合:

- **只攻击相邻格**(`Functions.Distance == 1`);
- **骑马时不能攻击**(攻击动作只在地面);
- **无主怪物直接可攻击;有主怪物(PetOwner != null)必须按 Shift 强制攻击**;
- 受 `AttackTime` 门控(冷却)。

## 4. 动作构造与目标选择(GameScene)

### 4.1 目标对象四元组

`GameScene.cs:88`:

```csharp
public MapObject MagicObject, MouseObject, TargetObject, FocusObject;
```

- **MouseObject**:鼠标指向的目标(悬停);
- **TargetObject**:当前锁定目标(近战/技能主目标);
- **MagicObject**:魔法当前作用目标(施法锁定);
- **FocusObject**:专注目标(部分技能/观察用)。

`MapObject.Race`(ObjectType.Monster / Player / Item)用于区分目标类型;`CanAttackTarget` 还校验目标是否在可攻击列表/是否同一阵营。

### 4.2 魔法施放流程(UseMagic(SpellKey key):GameScene.cs:2926-3455)

快捷键 SpellUse01-24 / 技能栏点击 → `UseMagic(SpellKey key)`:先按 `MagicType` 分技能分支(switch 内逐个 case),各分支完成锁定/校验后统一发包:

1. **ShoulderDash**(冲锋):校验 5 秒 ServerTime 冷却、WraithGrip 免疫 → 发 `C.Magic{Direction, Action=Spell, Type=ShoulderDash}`(不带 Target,方向位移型);
2. **DanceOfSwallow**(燕子啄):距离校验 → 锁定 TargetObject/MagicObject → 发 `C.Magic{Action=Spell, Type=DanceOfSwallow, Target=ObjectID}`;
3. **UseMagic 内各技能分支**(2926-3455):
   - MassBeckon / ReflectDamage / Endurance → direction 强制 Down(站桩施法);
   - Renounce / StrengthOfFaith → 无方向;
   - MagicShield / SuperiorMagicShield / FrostBite → buff 查重(已有不重复施放);
   - SeismicSlam / CrushingWave / ElementalSwords / TaecheonSword / FireSword / Repulsion / ScortchedEarth / LightningBeam / Teleportation / FrozenEarth / BlowEarth / GreaterFrozenEarth / ThunderStrike / MirrorImage / ElementalHurricane 等各有分支(选目标、算方向、填 Target/Location)。

施法结果统一走 `AttemptAction(Spell, ...)` → `C.Magic`(字段见 §5.6)。

## 5. 客户端发包(UserObject.AttemptAction,UserObject.cs:447-703)

`AttemptAction(ObjectAction action)` 是**客户端唯一的动作→发包出口**(MapControl/GameScene 都汇到这里)。前置门控:

- `CEnvir.Now < NextActionTime || ActionQueue.Count > 0` → return(上一个动作未播完);
- `CEnvir.Now < ServerTime` → return(等待服务端确认)。

### 5.1 Attack 的被动技能合并(454-610)

攻击前按当前"可发被动"逐项尝试把技能并入 `action.Extra[1]`(attackMagic),条件不足则跳过,按优先级链:

```
AttackMagic(主动挂载的魔法,如 Karma 需隐身+扣血/其他扣蓝)
→ CanPowerAttack   → Slaying(破血)
→ CanThrusting     → Thrusting(穿刺,需前方有目标 HasTarget)
→ CanHalfMoon      → HalfMoon(半月,需目标或前方命中)
→ CanDestructiveSurge → DestructiveSurge(重击)
→ CanPoisonAttack  → DragonBlood(龙血毒)
→ CanFlameSplash   → FlameSplash
→ CanWaningMoonAttack → WaningMoon
→ CanFullMoonAttack → CalamityOfFullMoon
→ CanDefensiveBlow → DefensiveBlow(防御姿态,需前方有目标)
→ CanBladeStorm    → BladeStorm
→ CanDragonRise    → DragonRise
→ CanFlamingSword  → FlamingSword
→ CanOffensiveBlow → OffensiveBlow(需前方有目标)
```

攻击元素(`action.Extra[2]`)取 `Functions.GetAttackElement(Stats)`;若项链(Amulet 槽)是 DarkStone 则用其亲和元素。**这些"Can*"布尔由服务端下发属性与 buff 决定,客户端只做本地预判,最终以服务端结算为准。**

### 5.2 各动作发包明细(619-703)

| 动作 | 冷却设置 | 发包 |
|---|---|---|
| Standing | NextActionTime += TurnTime(300ms) | `C.Turn{Direction}`;同时若没按右键则 `CanRun=false` |
| Harvest | NextActionTime += HarvestTime(600ms) | `C.Harvest{Direction}`,CanRun=false |
| Moving | MoveTime = Now + MoveTime(600ms) | `C.Move{Direction, Distance=MoveDistance}`,CanRun=true |
| Attack | attackDelay=max(800, AttackDelay(1500)-aspeed×47),AttackTime 记录;超重或 Neutralize 毒则 ×2 | `C.Attack{Direction, Action, AttackMagic}` |
| RangeAttack | 同上 | `C.RangeAttack{Direction, Target=(uint)Extra[0]}` |
| Spell | NextMagicTime = Now + MagicDelay(2000ms);超重/Neutralize +2000 | `C.Magic{Direction, Action=Spell, Type=MagicType, Target=AttackTargets[0]?, Location=MagicLocations[0]?}` |
| Fishing | AttackTime = Now + AttackDelay | `C.FishingCast{State, Direction, FloatLocation, CaughtFish}` |
| Mining | 同 Attack | `C.Mining{Direction}` |
| Taming | AttackTime = Now + AttackDelay | `C.Taming{State, Direction, ObjectID}` |
| Mount | — | return(不发;骑马走 `C.MountToggle` 快捷键) |

### 5.3 动作执行时序字段(UserObject.cs:210)

```csharp
public DateTime NextActionTime, ServerTime, AttackTime, NextRunTime, NextMagicTime,
               BuffTime = CEnvir.Now, LotusTime, CombatTime, MoveTime;
```

- `NextActionTime`:动作队列冷却(排队节流);
- `ServerTime`:服务端响应等待(移动确认、位移校正);
- `AttackTime`:攻击冷却(服务端也有一份,双端门控);
- `NextRunTime`:跑步节奏;
- `NextMagicTime`:魔法冷却(客户端侧 2s);
- `MoveTime`:移动节流(600ms/格)。

### 6.1 协议入口

`ServerLibrary/Envir/SConnection.cs` 共 **152 个 `Process(C.*)` 处理器**,均先校验 `Stage == GameStage.Game` 与方向范围再委托 `Player.Xxx(...)`。动作相关:

| C.* 包 | 服务端处理器行号 | 委托 |
|---|---|---|
| C.Turn | 411 | Player.Turn(13843) |
| C.Harvest | 419 | Player.Harvest(13885) |
| C.Move | 427 | Player.Move(14494) |
| C.AutoPathStart/Waypoint/Cancel/MoveStarted | 441/454/461/467 | 自动寻路 |
| C.Attack | 见 SConnection 清单 | Player.Attack(Direction, MagicType)(14630) |
| C.RangeAttack | 同上 | Player.RangeAttack(Direction, uint)(15032) |
| C.Magic | 同上 | Player.Magic(C.Magic)(14731) |
| C.Mining / C.FishingCast / C.Taming / C.TamingSuccess | 同上 | Player.Mining / Fishing / Taming |

### 6.2 服务端校验要点(PlayerObject)

**Move(14494)**:距离 1-2 普通移动,距离 3 需 `Horse != None`(骑马三格跑);逐格 `IsBlocking` 碰撞检测;移动移除隐身/透明 buff;广播 `S.ObjectMove{Direction, Location, Distance, Slow}`(Distance≥2 时客户端表现为跑步)。

**Attack(14630)**:ActionTime/AttackTime 门控 → 超时排队 `DelayedAction(ActionType.Attack)` 或回 `S.UserLocation` 校正;`attackDelay = max(800, Globals.AttackDelay - aspeed*ASpeedRate)`,慢毒(Neutralize)/超重再叠加;汇总范围内 MagicObjects 攻击技能后结算并广播 `S.ObjectAttack{ObjectID, Direction, Location, AttackMagic, AttackElement, TargetID, Slow}`。

**Magic(14731)**:校验魔法等级/冷却/蓝耗 → 按 MagicType 分派到 `ServerLibrary/Models/Magics/` 下的技能实现类(每个技能一个文件,如 Assassin/DanceOfSwallow.cs:77 `Player.Broadcast(new S.ObjectAttack{...})`);技能实现决定目标列表与 `S.ObjectMagic{Type, Targets, Locations, Cast=true}` 或直接伤害。

**RangeAttack(15032)**:目标 ID 校验 → `S.ObjectRangeAttack{Targets: List<uint>}` 多目标。

### 7.2 动作队列与帧推进(Client/Models/MapObject.cs)

- `ActionQueue`(345 行):`List<ObjectAction>`,最多缓存若干动作,先进先出;
- `UpdateFrame`(595 行起):`CurrentFrame.GetFrame()` 取当前帧;队列>1 时加速播放(追赶);帧播完(`frame == FrameCount`)→ `DoNextAction()`(610-618)弹下一个动作;
- `SetAction`(749 行):收到新动作时重置 `CurrentFrame = Frames[animation]`,并挂载特效/弹道/音效(见 §8);
- Moving/Pushed 按 `MoveDistance` + 帧数做坐标插值(SmoothMove)。

## 8. 渲染细节:帧表 / 图集 / 音效 / 特效

### 8.1 帧表(FrameSet.cs)

- 玩家帧表在 `LibraryCore/FrameSet.cs` Players 段(560-580 附近,Combat1/2 有自定义延迟),每动画 = (起始帧, 帧数, 每帧延迟 ms);
- 帧类 `Frame`(1076-1154):StartIndex/FrameCount/OffSet/Reversed/StaticSpeed/Delays[],`GetFrame()` 按时间推进,帧数播完回调 `DoNextAction()`;
- 图集内定位:`BodyFrame = DrawFrame + (BodyShape % 10) * BodyOffSet`(BodyOffSet=1000),即每个玩家图集(如 Hum_XX)每 1000 帧一个形象槽。

### 8.2 音效与特效钩子(MapObject.cs:5179-5199)

- `FrameIndexChanged` 中按帧号挂音效/特效:近战 Combat1 第 1 帧播 AttackSound;远程 Combat2 第 4 帧 `CreateProjectile()` + 攻击音;Die 第 0 帧播 DieSound;Struck 受击在 `GameScene.Game.StruckEnabled` 下播 StruckSound;
- 玩家技能特效在 `PlayerObject.SetAction`(806 行)按 MagicType 加 MirEffect/音效,如 SweetBrier/Karma 按 `LibraryWeaponShape >= 1200/>= 1100` 使用 `LibraryFile.MagicEx4` 图集;
- 骑马音效(UserObject.cs:755-761):马走 HourseWalking 帧 1/4 踩点,马跑 HorseRunning 帧 1 踩点。

### 8.3 移动插值

- `SmoothMove`(GameScene Process 中):客户端收到 `S.ObjectMove` 后在 Slow 时间窗内按方向与 Distance 插值,避免瞬移;自己移动以 `ServerTime` 对齐服务端节奏。
