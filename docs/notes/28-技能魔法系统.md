## 3. 类名 ↔ MagicType 映射模式与注册机制

### 3.1 映射模式(全部 190 文件一致)

每个技能文件在类声明上方一行放 `[MagicType(MagicType.X)]` 特性,类名与枚举项同名,继承 `MagicObject`:

```csharp
// ServerLibrary/Models/Magics/Wizard/FireBall.cs:8-10
[MagicType(MagicType.FireBall)]
public class FireBall : MagicObject
```

抽查 20+ 文件全部符合该模式。**仅有的例外**:`Taoist/GreaterPoisonDust.cs:6` 类名 `GreaterPoisonDust` 映射 `MagicType.AugmentPoisonDust = 322`(类名≠枚举名,枚举名是"强化毒粉"语义)。`[MagicType]` 特性定义在 `MagicObject.cs:422-431`(AttributeUsage@422,class@423):`[AttributeUsage(AttributeTargets.Class, AllowMultiple = true)]`——允许一个类注册多个 MagicType(当前仓库无此用例)。

### 3.2 反射注册(SEnvir.cs)

- 静态收集:`SEnvir.CreateMagic()` `ServerLibrary/Envir/SEnvir.cs:1244-1255` —— 扫描 `MagicObject` 程序集内所有非抽象、基类为 `MagicObject`、且带 `[MagicType]` 特性的类型,存入 `SEnvir.MagicTypes`(静态 `List<Type>`,`SEnvir.cs:318`);启动时调用(`SEnvir.cs:570`)。
- 实例化:`PlayerObject.SetupMagic(UserMagic)` `PlayerObject.cs:244-257` —— 按 `userMagic.Info.Magic` 在 MagicTypes 中找特性匹配的类型,`Activator.CreateInstance(found, this, userMagic)` 构造 `MagicObject` 子类,存入玩家 `MagicObjects` 字典(`MagicList`:`MagicObject.cs:357-375`,按 Type 排序缓存 `OrderedKeys`)。

### 3.3 技能静态数据 MagicInfo(LibraryCore/SystemModels/MagicInfo.cs)

每个 MagicType 对应一条 MagicInfo 数据(DB 配置):Name / Magic(MagicType,IsIdentity)/ Class(MirClass)/ School(MagicSchool:Active/Passive/Toggle/Horse/Discipline 等)/ Property(MagicProperty)/ Icon / MinBasePower / MaxBasePower / MinLevelPower / MaxLevelPower / BaseCost / LevelCost / NeedLevel1-3 / Experience1-3 / Delay(毫秒,技能冷却)/ Description。`UserMagic.Cost => Info.BaseCost + Level * Info.LevelCost / 3`(`UserMagic.cs:189`);`GetPower()` 按 `Min/MaxBasePower + Level * Min/MaxLevelPower/3` 随机取整(`UserMagic.cs:196-205`)——**技能威力与法力消耗都随等级线性成长**。

## 7. 代表技能深度剖析(每职业 5 个,实际代码行为)

### 7.1 Wizard 法师

**FireBall(火球,FireBall.cs:8-90)** — `Element = Fire`(10)。`GetBurn/GetBurnLevel`(16-37)先查强化技能 `MagicType.Burning`(`GetAugmentedSkill`),有则用其威力/等级(火球触发灼烧,强化链)。基础弹道由基类链路:MagicCast 锁定目标 → S.ObjectMagic 广播 → 客户端 MirProjectile 飞行(Client/Models/MapObject.cs:845,Magic 图库 420 帧) → 命中后 DelayedMagicDamage 结算。

**MagicShield(魔法盾,MagicShield.cs:9-47)** — `UpdateCombatTime = false`(11)。MagicCast(15-26):`Ob=null`(无需目标),入队 `DelayedAction(Now+1100ms, DelayMagic, Type)`。MagicComplete(28-45):已有 MagicShield 或 SuperiorMagicShield buff 则 return;否则 `BuffAdd(MagicShield, 30 + Level*20 + MC/2 + PhantomAttack*2 秒, Stats{ MagicShield=50 })`——**护盾时长随等级/MC/幻攻成长**,是典型"施放延迟 1.1s → 挂 Buff"模板。

**Teleportation(传送,Teleportation.cs:9-56)** — `UpdateCombatTime=false`(11)。MagicCast(15-27)入队 500ms DelayMagic;MagicComplete(29-54):`Map.Info.SkillDelay > 0` 的地图禁传送(聊天提示);成功率 `Random.Next(MagicMaxLevel+5) > 2 + Level*2` 失败则 return(原版传送有失败率);成功 `Player.Teleport(CurrentMap, GetRandomLocation())` 随机落点 + 练级。

**MeteorShower(流星火雨,MeteorShower.cs:9-102)** — `Element=Fire`(10);`GetBurn` 走 Burning 强化链(16-32);MagicCast 按地面区域入队多目标 DelayedAction;`ModifyPowerAdditionner` 覆写伤害加成。AOE 范围魔法模板。

**MirrorImage(镜影分身,MirrorImage.cs:11-93)** — MagicCast(15-38):`Functions.InRange` 校验(MagicRange)后 `Locations.Add(location)` + 500ms DelayMagic。MagicComplete(40-91):从 `Equipment[Amulet]` 读 DarkStone 元素亲和(Fire/Ice/Lightning/Wind 四选一,44-56),无元素则 return;已有镜影宠物则 return;创建 `M.MirrorImage` 怪物(`MonsterFlag.MirrorImage`),`ExplodeTime = Now + (Level>0 ? Level*5 : 5) 秒`(到期自爆),`TameTime = +365 天`,Spawn 后 `Broadcast(S.ObjectEffect{ Effect=MirrorImage })` 并 `Player.Pets.Add`——**召唤系模板:宠物结构复用 MonsterObject + PetOwner 绑定**。

### 7.2 Warrior 战士

**HundredFist(百裂拳,HundredFist.cs:8-166)** — 直线型位移攻击。MagicCast(16-55):`CanAttackTarget` 校验;`IsStraightEightDirection` 直线校验;WraithGrip 毒禁止;`response.Direction` = 朝目标方向;`Broadcast(S.MapEffect{ Effect=HundredFist })` 地面特效;入队 300ms DelayMagic;**立即 `MagicConsume()` + `MagicCooldown()`**——消耗/冷却在施放瞬间而非结算时。MagicComplete 内 `TargetPush` 逐格推怪(CanPushTarget + ob.Pushed(Direction, distance))。

**ShoulderDash(冲撞,ShoulderDash.cs:8-271)** — WraithGrip 毒/已有 Dash buff 禁止(20-25);`distance = Magic.GetPower()`;`BuffAdd(Dash, distance*300ms, ..., hidden:true)`(29,`hidden` 唯一使用点——客户端不显示图标但服务端有状态);入队 `DelayedAction(Now, DelayMagic, Type, distance, 0, null)`;立即消耗+冷却。MagicComplete 逐格推进 `FinalizeDash`,撞到目标 `TryPush`(Pushed(Direction,1))。

**Beckon(吸引,Beckon.cs:8-111)** — `Ob = target`(16)。MagicComplete(27-94)按 `ob.Race` 分派:Player——等级低于施法者且无 Endurance buff,成功率 `Random.Next(MagicMaxLevel+6) > 4+Level`;Monster——非 Boss 且 `CanPush`,`Random > 2+Level*2`;Item——道具也可吸;成功 `ob.Teleport(CurrentMap, Functions.Move(CurrentLocation, Direction))` 吸到面前。**冷却特例**:PvP 后 30 秒内 `delay *= 10`,`MagicCooldown(null, delay)` 传参覆盖。

**Invincibility(无敌,Invincibility.cs:9-47)** — `UpdateCombatTime=false`(11);MagicCast 方向固定 `Down`(19)+500ms;MagicComplete(28-44):`BuffAdd(Invincibility, 5+Level 秒, Stats{ Invincibility=1 })`。

### 7.3 Taoist 道士

**Heal(治愈,Heal.cs:8-75)** — `UpdateCombatTime=false`(11)。MagicCast(15-32):`CanHelpTarget(target)` 不通过则 `response.Ob = Player`(目标改自己),`Targets.Add(Ob.ObjectID)` + 500ms。MagicComplete(34-72):目标满血/已有 Heal buff 则 return;`GetAugmentedSkill(EmpoweredHealing)` 强化链加 `bonus = 强化威力`、`cap += (1+强化等级)*30`;`BuffAdd(Heal, Stats{ Healing = 技能威力+SC+HolyAttack*2+bonus, HealingCap = cap }, 时长 = Healing/HealingCap 秒, TickFrequency=1s)`——**Heal 是 Tick 型 Buff 而非瞬间回血**:每 Tick 回 Healing 点血,到 HealingCap 上限。**属性流三元素:技能威力(GetPower)+ 道术(SC)+ 圣攻(HolyAttack)**。

**Resurrection(复活,Resurrection.cs:8-123)** — `UpdateCombatTime=false`(11)。MagicCast(15-48):`InGroup(target) || InGuild(target)` 且目标死亡才计入 `realTargets`;`AugmentResurrection` 强化时可按冷却额外多目标;MagicComplete 复活结算。组队/行会限定复活模板。

**SummonSkeleton(召唤骷髅,SummonSkeleton.cs:8-95)** — MagicCast(14-37):`Player.UseAmulet(1, 0)` 消耗护身符(失败 Cast=false 不施放);查 `MonsterFlag.Skeleton` 的 MonsterInfo 入队 500ms。MagicComplete(39-92):已有同种宠物 → `PetRecall()` 召回;`Pets.Count >= 2` 上限拒绝;`MonsterObject.GetMonster(info)` 创建,`PetOwner = Player`,`Magics.Add(Magic)`(宠物继承技能),`SummonLevel = Magic.Level*2`,TameTime +365 天;StrengthOfFaith/DemonicRecovery 强化挂给宠物;落点不可行则 `Spawn(CurrentMap, CurrentLocation)` 兜底。

**PoisonCloud(施毒术,PoisonCloud.cs:8-72)** — MagicCast(14-30):`Locations.Add(CurrentLocation)`,`GetCells(玩家位置, 0, 2)` 取 2 格半径全部格子,**每格入队一个 2500ms DelayMagic**(群毒延迟落地)。MagicComplete(32-69):对格内每个可攻击对象 `ApplyPoison(Poison{ Value = 等级+1+Level/14, Type=Green(绿毒), TickCount = 威力/2, TickFrequency=2s })`——**绿毒:每 2 秒一次伤害,总次数=威力/2**;宠物自动转向目标。

### 7.4 Assassin 刺客

**Cloak(斗篷,Cloak.cs:8-119)** — `UpdateCombatTime=false`(11)。**覆写 CheckCost(15-30)**:已有 Cloak buff 免费;`SEnvir.Now < CombatTime+10s` 战斗中禁止(攻击后 10 秒内不能隐身);HP 成本:`Health*Cost/1000 >= CurrentHP || CurrentHP < Health/10` 拒绝(血太少不能开)。**覆写 MagicFinalise(空,49)**——基类 MagicFinalise 会移除 Cloak,隐身技能覆写为空以保住斗篷。MagicComplete 挂 `BuffType.Cloak`,效果见文档 29(清仇恨+半透明)。

**FatalBlow(致命一击,FatalBlow.cs:8-49)** — **`AttackSkill = true`(11)**:普攻挂钩技能。`AttackCast`(15-23)把自身加入 `response.Magics`。`ModifyPowerAdditionner`(25-39):目标血量 `<30%` 时 `Random.Next(MagicMaxLevel+1) <= Level` 概率 `power += power*GetPower()/100`(斩杀加成)。**普攻技能模板:AttackCast 注册 → ModifyPower 加成 → AttackComplete 练级**。

**SummonPuppet(召唤傀儡,SummonPuppet.cs:8-171)** — `Element=Fire`(10);`UpdateCombatTime=false`(11)。500ms 延迟召唤;`CloakEnd(UserMagic, forceGhost)` 傀儡死亡/斗篷结束的联动(傀儡继承 Cloak 效果,斗篷结束强制幽灵形态)。

**Massacre(大屠杀,Massacre.cs:8-47)** — **`HasMassacre = true`(12,自定义技能)**。`AttackCompletePassive`(14-45):普攻杀死怪物且 `CurrentHP < 0` 时,若 `CanUseMagic()` 把 `MagicType.Massacre` 加入 types,`power = |CurrentHP| * GetPower()/100`,对 `GetTargets(地图, 击杀点, 1)` 半径 1 格内非 Boss 怪物入队 `DelayedAction(Now+600ms, DelayAttack, t, types, false, power)`——**击杀传染爆炸(尸爆)**。被动技能模板:不主动施放,普攻击杀自动触发。

**Stealth(潜行,Stealth.cs)** — `MagicFinalise` 引用点:基类 MagicFinalise 检查 `GetMagic(Stealth) && stealth.CheckCloak()`,满足才保留 Cloak buff——**Stealth 是 Cloak 的伴生判定技能**(潜行状态下斗篷不消失)。

### 9.3 冷却:MagicCooldown 双通道

- **服务端发**:`MagicObject.MagicCooldown`(MagicObject.cs:343-351)——`Magic.Cooldown = Now + Delay(Info.Delay 毫秒)`,`Player.Enqueue(S.MagicCooldown{ InfoIndex, Delay })`;Superman 跳过;Beckon PvP ×10 等传参覆盖;莲花系(FullBloom/RedLotus/WhiteLotus/SweetBrier)链式冷却另有调用(FullBloom.cs:61-62 等)。
- **客户端收**:`S.MagicCooldown` → `CConnection.Process`(CConnection.cs:1902-1905)→ `User.Magics[p.Info].NextCast = Now + Delay`。
- **客户端显示**:MagicBarDialog(Client/Scenes/Views/MagicBarDialog.cs)——`Cooldowns` 字典(Dictionary<SpellKey, DXLabel>,52);每个快捷键图标叠 34×34 半透明黑底标签(134-137);`Process()` 每帧(292-327)对 toggle 技能(305-313)与普通技能判 `CEnvir.Now >= magic.NextCast && Now >= ToggleTime` 隐藏,否则显示 `Math.Ceiling(remaining.TotalSeconds)+"s"` 秒数(321),>5s 金色、否则红色(323-326)。**数字式秒数,无环形 CD**。
