# 旧版客户端点击动作目录

本目录以 `Client/Scenes/Views`、`Client/Controls` 中的 `MouseClick`/`GuiInput` 回调，以及回调实际发送的 `LibraryCore/Network/ClientPackets.cs` 为依据。迁移状态以 Godot 当前代码为准；“已移植”表示已有 Godot 点击入口并发送同类请求，不能仅凭同名窗口判断。

## 世界地图

| 旧版动作 | 请求/效果 | Godot |
|---|---|---|
| 左键地图 NPC | `NPCCall` | 已移植 |
| 左键地图掉落物 | `PickUp` | 已移植 |
| 左键相邻空格、装备镐子 | `Mining` | 已移植 |
| Ctrl+右键玩家 | `Inspect` | 已移植 |
| 地图双击寻路 | `AutoPathWaypoint`、`AutoPathMoveStarted` | 已移植 |
| 选中可掉落货币后点地图 | `CurrencyDrop` | 已移植 |
| 普通移动/攻击/技能/坐骑/钓鱼/驯马 | 对应移动、攻击、魔法、`Taming`、`FishingCast` 请求 | 已移植 |

## NPC 与加工

NPC 对话按钮、购买/出售、修理、精炼、精炼石、饰品升级/重置、武器制作、碎片、镶嵌/合成、婚戒、伙伴管理、骰子/Yut、任务选项均已接入对应 `NPC*` 请求。大师精炼的“评估”和“开始精炼”分开发送；骰子/Yut 的“开始”和“领取结果”分开发送。

## 任务与里程碑

任务日志支持接受、追踪、放弃、完成和可选奖励；任务物品点击领取/使用按旧版上下文处理。里程碑达成弹窗支持领取，网络层提供 `MilestoneNotify`、`MilestoneActive` 和 `MilestoneClaim`。

## 社交、交易、邮件、行会

- 好友添加/删除、在线状态循环、屏蔽添加/删除、聊天及物品链接均已接入。
- 交易请求接受/拒绝、添加物品/金币、确认、关闭、解锁状态均已接入。
- 邮件发送、删除、打开、附件领取，以及行会仓库物品移动均已接入。
- 行会创建、邀请、成员编辑/踢出、公告、税率、扩容、战争、攻城、城门/守卫维护、旗帜和颜色均已接入。
- 组队邀请、允许组队、LFG 发布/撤销、组队通知均已接入。

## 角色、技能、商城和系统

- 属性、修炼、隐士加点、城镇复活、角色外观修改和婚戒传送均已接入。
- 技能使用、技能开关、快捷键绑定、观察模式和头盔显示均已接入。
- 商城购买、收藏、赠送、货币切换、充值地址跳转均已接入。
- 设置页语言切换发送 `SelectLanguage`；退出前发送 `Logout`；选角页删除角色使用持久化 `CheckSum` 发送 `DeleteCharacter`。

## 验证方法

协议覆盖审计命令：

```text
对照 Client 中实际 Enqueue(new C.X) 的 X，检查 GodotClient 是否存在同一 X 的发送入口。
```

当前审计结果为旧版点击回调中使用的客户端请求均能在 Godot 代码中找到对应实现；Godot C# 项目使用 `dotnet build GodotClient/ZirconClient.csproj --no-restore` 验证。

登录页同时提供修改密码、申请/重置密码、激活账号和申请激活码入口，并使用持久化校验串发送对应旧版请求。
