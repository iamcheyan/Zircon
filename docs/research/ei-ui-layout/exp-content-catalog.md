# EI `Magic.exp` 技能内容目录

更新时间：2026-08-09

`Magic.exp` 已通过原版 `Mir3.exe` 的解码例程恢复为 GB18030 文本，并由
`Tools/content/parse_mir3_magic_exp.py` 解析为逐条 JSON。当前恢复出 50 条技能记录，
每条包含原版 ID、中文名、属性、元素、1–4 级门槛、修炼值和原版说明。

```bash
python3 Tools/content/parse_mir3_magic_exp.py \
  /home/tetsuya/NAS/TMP/EI传奇3.0客户端/Magic.exp
```

产物：

- `magic-exp-records.json`：机器可读逐条记录，带原始区块和 SHA-256。
- `Magic.exp.decoded.txt`：解码后的原始 GB18030 内容转 UTF-8 保存。

## 内容分组

| 原版区段标记 | 当前记录数 | 内容特征 |
|---|---:|---|
| 文件开头至第二段起点 | 8 | 战士候选：基础剑术与后续剑系技能 |
| 第二段（第 9–31 条） | 23 | 法师候选：自然系/灵魂系技能 |
| 第三段（第 32–50 条） | 19 | 道士候选：灵魂系技能 |

三段的起点技能 ID 分别为 `3`、`1`、`2`。数字本身是技能 ID，不是独立的
class-header；“战士/法师/道士”是根据文件顺序和技能内容得到的候选语义，记录中
保留了 `primary-file-order-plus-content-candidate` 证据等级。它们不直接等同于
客户端窗口的八个“火/冰/电/风/神圣/黑暗/幻影/剑”按钮；窗口页签与这些记录的最终
映射仍需追踪 `0x0043A440` 和技能控件回调。

## 已可直接用于百科的字段

- 原版技能 ID：来自每个 `#数字` 记录头。
- 中文名称：来自方括号标题。
- 属性、元素：来自原版文本字段。
- 1–3 级学习等级和修炼值：均为明确数字。
- 第 4 级：原版多数写作“未知”，应保持未知，不补猜测。
- 说明：保留原文；错别字、旧译名和 `?属性` 不应擅自现代化。

这批资料比服务端 `magic.dat` 更直接地反映 EI 客户端技能窗口会显示什么，
但它仍不包含所有战斗数值。威力、耗蓝和动画帧要分别从 `magic.dat`、WIL
资源和代码读取路径交叉确认。
