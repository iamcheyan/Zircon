# Godot 渲染审计与修复清单

更新时间：2026-08-07

## 目标

让 Godot 客户端的地图、玩家、怪物、NPC、物品和特效达到原版 Mir 客户端的绘制语义：同一套坐标、基线、行排序、阴影、染色、混合、光照和 UI/标签流程。

## 修复顺序

1. 建立统一 `SpriteDraw` 绘制入口，集中处理主图、阴影、Overlay、偏移、透明度和缩放。
2. 修复 ZL 的主图/Shadow/Overlay 数据读取，并为玩家、怪物、NPC、物品补齐阴影。
3. 恢复玩家装备染色、坐骑及坐骑特殊效果。
4. 恢复物品稀有度光效、名称和焦点框。
5. 恢复对象名称、聊天、毒状态、伤害数字和目标描边。
6. 接入对象光源、特效光源和昼夜颜色。
7. 补齐怪物特殊分层、Blend 和大型对象基线。
8. 用 headless 测试、编译和游戏截图逐项验收，并在本表更新状态。

## 验收标准

- 人物、NPC、怪物脚下可见且位置正确的阴影；人物移动时阴影随基线移动。
- 装备染色与原版角色界面颜色一致，Overlay 不改变透明轮廓。
- 物品不再像悬浮图标，焦点框和稀有度光效跟随物品格坐标。
- 角色、对象和特效不会穿过应当遮挡它们的建筑/地形。
- 夜晚、黄昏、雨雪和局部光源能够同时生效。
- `dotnet build GodotClient/ZirconClient.csproj --no-restore` 无错误。
- MapTest/headless 渲染测试通过，且运行时无连续图片解码错误。
